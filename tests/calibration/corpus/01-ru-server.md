# Установка сервера

Сервер эмбеддингов запускается отдельным процессом. Скачайте GGUF-модель и проверьте контрольную сумму файла. Флаг --embedding обязателен, иначе endpoint /v1/embeddings вернёт ошибку.

## Настройка

Укажите порт 9932 и хост 127.0.0.1. Для GPU добавьте -ngl 99, для CPU оставьте значение по умолчанию. Параметр --pooling mean соответствует конфигурации модели.

## Проверка

Отправьте тестовый запрос через curl. Ответ должен содержать 768 чисел с единичной L2-нормой. Первый вызов после простоя занимает около десяти секунд из-за прогрева CUDA.

# Рецепт пасты

Вскипятите воду в большой кастрюле. Добавьте соль из расчёта десять граммов на литр. Опустите пасту и варите девять минут, периодически помешивая.

Слейте воду, оставив полстакана для соуса. Смешайте пасту с оливковым маслом и тёртым пармезаном. Подавайте сразу, пока соус не остыл.

# Фондовый рынок

Индекс упал на три процента за торговую сессию. Инвесторы фиксируют убытки и переводят средства в облигации. Аналитики связывают падение с ростом ставки и слабой отчётностью технологических компаний.

Волатильность остаётся повышенной. Рекомендуется диверсифицировать портфель и не принимать решения на эмоциях. Долгосрочные вкладчики обычно переживают такие периоды без изменений стратегии.
