# Password hygiene

Use a password manager to generate unique passwords for every service. Length matters more than complexity; a long passphrase resists guessing better than a short cryptic string. Never reuse a password between work and personal accounts.

Enable multi-factor authentication wherever possible. Prefer hardware keys or app-based codes over SMS. Store recovery codes offline in a secure place.

# Phishing

Treat urgent requests for credentials as hostile until verified. Check the sender's domain, not just the display name. Hover over links to inspect the real destination before clicking.

Report suspicious messages to the security team instead of forwarding them to colleagues. Do not open unexpected attachments, even from known contacts. When in doubt, call the person using a number you already trust.

# Data handling

Classify data before sharing it. Customer records and credentials require encryption in transit and at rest. Use approved storage locations rather than personal cloud drives.

Delete data when it is no longer needed. Grant the minimum access required for a task. Review permissions quarterly and revoke accounts promptly when people leave.
